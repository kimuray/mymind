# 自律モードで issue を連続して片付ける

自律モードで作業します。`.claude/rules/autonomy.md` を読み、その「ループ」に従って、着手できる issue がなくなるまで作業を続けてください。

- 各 issue の着手前にユーザーの了承を求めないでください
- 人の判断が必要になったら、その場で待たずに「保留にするとき」の手順で保留にし、次の issue に移ってください
- マージは `node scripts/merge-if-allowed.mjs <PR番号>` だけを使ってください
- 終了時は「終了するとき」の形式で報告してください
