# モックアップのソース（Figma 準備までの参照用）

キャンバスで作ったモックアップの元ファイルです。Figma（issue 004）が用意できるまで、画面の見た目の参照として使います。Figma の準備ができたら、Figma を正本にし、このディレクトリは参考資料として残します。

## ファイル

| ファイル | 画面 |
|---|---|
| `PC_Today.dc.html` | 今日（3ペイン、タスクリスト、詳細ペインの状態の履歴、コマンドパレット） |
| `PC_Morning.dc.html` | 朝の計画（持ち越しの判断、バックログから追加、昨日のFBと調子） |
| `PC_Reflection.dc.html` | 振り返り（Markdown の書く／プレビュー、FB の4状態） |
| `PC_Backlog.dc.html` | バックログと棚卸し |
| `PC_Week.dc.html` | タイムライン（2週間、調子のレーン、内訳） |
| `PC_Month.dc.html` | カレンダー（日の詳細、FB の後追い依頼、月の総括） |
| `Mame.dc.html` | マメ（`mood` と `size` を受け取る部品。7つの表情の形状の表を含む） |
| `Mascot.dc.html` | マメの表情一覧 |

## 読み方

これらはブラウザで直接開いても表示されません（専用の実行環境が必要です）。HTML とインラインスタイル、末尾の `<script>` 内の `renderVals()` を読んで、構造と値を参照してください。

- `{{name}}` は `renderVals()` が返す値の差し込み、`<sc-for>` は繰り返し、`<sc-if>` は条件表示です
- `<dc-import name="Mame" mood="..." size="...">` は `Mame.dc.html` の部品を埋め込んでいます
- 色や角の丸みは直書きされていますが、実装では必ず DESIGN.md のトークン（CSS 変数）に置き換えてください。値が DESIGN.md と食い違っている場合は、DESIGN.md を正とします
- 表示されているタスク名や数字はサンプルです
- モックアップは Google Fonts からフォントを読み込んでいますが、実装ではフォントを同梱して自前で配信します（NFR-10）
