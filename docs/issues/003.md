## 背景

launchd で起動したプロセスはシェルの PATH を読み込まないため、`claude` / `codex` が見つからない、認証情報に届かないといった問題が起きやすい。issue 001 の結果に依存する。

## 人の作業が必要な理由

利用者の Mac での launchd 設定が必要なため。エージェントは着手せず、準備ができたら Yoshihiro がラベルを `status:ready` に変える。

## やること

- [ ] launchd の plist を生成するスクリプトを用意する（PATH、作業ディレクトリ、ログの出力先を明示）
- [ ] 起動時に `claude` / `codex` の実行ファイルの場所とバージョンを確認し、見つからなければ画面と通知で知らせる
- [ ] キーチェーンや `~/.codex` の認証情報が子プロセスから使えるか確認する

## 完了条件

- ログイン後に自動起動したサーバーから、FBの生成が成功する
- エージェントが見つからない場合に、原因が画面に表示される
