## 背景

親をバックログへ移したときの子、未完了の子がある親の中止、子だけを今日に入れたときの親、3階層目を作ろうとしたときの挙動が未定。

## やること

- [ ] 各ケースの挙動を Yoshihiro が決める
- [ ] 決定を requirements.md と architecture.md 4.3 に反映する

## 暫定決定（エージェントはこれに従って実装してよい）

- 親をバックログへ移すと、未完了の子も一緒にバックログへ移す。着手中の子は FR-T06 に従って中断にする
- 未完了の子がある親を中止しようとしたら、確認を出し、了承されたら未完了の子もすべて中止にする
- 未完了の子がある親を完了にしようとしたら、確認を出し、了承されたら未完了の子もすべて完了にする
- 子だけを今日に入れても、親は計画に入れない（画面では親の名前をラベルとして表示するだけ）
- 3階層目を作る操作（孫への `Tab`）は受け付けず、「2階層まで」とトーストで知らせる
