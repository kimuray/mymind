## 背景

各画面のURL、通知から開くリンク、ブラウザの戻る操作の扱いが未定。案：`/`（今日）、`/morning`、`/reflection/:day?`、`/backlog`、`/timeline?from=&to=`、`/calendar/:ym?/:day?`。

## やること

- [ ] 案をもとに URL 設計を決める
- [ ] 通知のリンク先と Figma のフレーム名を対応させる

## 暫定決定（エージェントはこれに従って実装してよい）

| 画面 | URL |
|---|---|
| 今日 | `/` |
| 朝の計画 | `/morning` |
| 振り返り | `/reflection`（今日）、`/reflection/:day`（過去の日） |
| バックログ | `/backlog` |
| タイムライン | `/timeline?from=YYYY-MM-DD&to=YYYY-MM-DD` |
| カレンダー | `/calendar/:ym`、日付を選んだ状態は `/calendar/:ym/:day` |

- 画面の移動はブラウザの履歴に積み、戻る操作で前の画面に戻れる。詳細ペインの選択状態は URL に含めない
- 通知のリンク先は、朝＝`/morning`、夜＝`/reflection`、棚卸し＝`/backlog?review=stale`

## 完了条件
