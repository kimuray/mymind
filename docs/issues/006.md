## 背景

pnpm 10 は依存パッケージのインストール時スクリプトを標準で実行しない。issue 002 の結果に依存する。

## やること

- [ ] ビルドが必要な依存関係を洗い出し、`pnpm-workspace.yaml` で明示的に許可する
- [ ] サンドボックス内で `pnpm install`、`pnpm test`、`pnpm test:e2e` が通るか確認し、足りない通信先や書き込み先を `.claude/settings.json` に追加する
- [ ] macOS で Playwright が起動しない場合、`sandbox.network.allowMachLookup` の設定を検討する

## 完了条件

- クリーンな状態から、サンドボックス有効の Claude Code で `pnpm install && pnpm check && pnpm test:e2e` が通る
