## 背景

issue の登録、ラベル、マイルストーン、main ブランチの保護を行う。

## 人の作業が必要な理由

GitHub のリポジトリ作成と認証が必要なため。エージェントは着手しない。

## やること

- [ ] リポジトリを作り、`node scripts/github-setup.mjs` を実行する
- [ ] `node scripts/issues-to-github.mjs` で issue を登録する
- [ ] 登録後、`docs/issues/` を削除する PR を作る

## 完了条件

- GitHub に issue とラベルが揃い、main への直接 push が拒否される（プランの制約で保護を設定できない場合は、その旨を記録する）
