## 暫定決定（エージェントはこれに従って運用してよい）

次のいずれかに該当する PR は、Yoshihiro のレビューが必須（`review:required`）。それ以外は、CI が通ればエージェントが `scripts/merge-if-allowed.mjs` でマージしてよい。判定はスクリプトが変更ファイルから機械的に行う。

- `packages/domain/src/` の状態遷移・自動ルール（`status.ts`、`rules*.ts`）
- DB のスキーマとマイグレーション（`packages/db/src/schema*`、`packages/db/migrations/`）
- `prompts/`
- セキュリティに関わるコード（`apps/server/src/security/`）
- `docs/adr/`、`docs/requirements.md`、`AGENTS.md`、`CLAUDE.md`、`.claude/rules/`
- ハーネスの設定（`.claude/`、`.github/`、`biome.json`、`.dependency-cruiser.cjs`、`scripts/merge-if-allowed.mjs`）
