# Issue 一覧（GitHub 登録前）

GitHub に登録するまでの間、issue をここで管理します。各ファイルの先頭にタイトル、ラベル、マイルストーン、依存する issue（`depends_on`）を書いてあり、`scripts/issues-to-github.mjs` でまとめて GitHub に登録できます。登録後は GitHub を正本にし、このディレクトリは削除します（issue 029）。
