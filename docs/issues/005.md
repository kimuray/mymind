## 背景

ADR-0007 の実装。issue 002（DB）と並行可能だが、サーバーの雛形が必要。

## やること

- [ ] Hono サーバーの雛形（127.0.0.1 のみで待ち受け、ポート使用中なら失敗）
- [ ] Host の許可リスト、`Sec-Fetch-Site`・`Origin`・`X-Mymind-Token` の検証ミドルウェア
- [ ] セッショントークンの生成、データディレクトリへの書き出し、meta タグへの埋め込み（本番と Vite プラグイン）
- [ ] Vite の `/api` プロキシ
- [ ] 本番ビルドの CSP（CodeMirror のノンスを含む）
- [ ] Playwright の webServer を本番ビルドに向ける
- [ ] ロックファイルによる二重起動の防止（NFR-20）
- [ ] 待ち受け先を `MYMIND_HOST` で指定できるようにする。`0.0.0.0` は `MYMIND_IN_CONTAINER=1` のときだけ許可し、それ以外では起動を拒否する（ADR-0010）
- [ ] `docker compose up dev` で起動し、ホストのブラウザから開けることを確かめる

## 完了条件

- 外部オリジンからの状態変更リクエストが拒否される結合テストがある
- Host が不正なリクエストが拒否されるテストがある
- E2E が本番ビルドに対して実行され、CSP 違反が出ない
