## 背景

ADR-0005。FB生成でClaude Code / Codexをヘッドレス起動する方法は推測で実装すると動かない可能性が高い。

## 人の作業が必要な理由

Claude Code / Codex にログインした状態の実機が必要なため。エージェントは着手せず、準備ができたら Yoshihiro がラベルを `status:ready` に変える。

## やること

- [ ] 両CLIのヘッドレス起動コマンドとフラグ（標準入力での受け渡し、出力形式）を確認する
- [ ] ツールの使用とファイル書き込みを無効化する設定と、その確認方法を確かめる
- [ ] 未ログイン・利用上限・古いバージョンの状態で、終了コードと出力がどうなるかを記録する
- [ ] 1回の生成時間を計測し、タイムアウトの初期値を提案する
- [ ] `packages/agent` に最小のアダプタと、実出力の fixture を追加する

## 完了条件

- ADR-0005 を「採用」に更新し、確定した起動方法を追記している
- 両アダプタで `prompts/daily-feedback.md` を実行し、スキーマ検証を通る出力が得られる
- 検証できなかった項目が明記されている
