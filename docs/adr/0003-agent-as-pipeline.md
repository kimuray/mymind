# ADR-0003：エージェントは決まった入出力のパイプラインとして使う

- ステータス：採用
- 日付：2026-09-22

## 背景

FB生成では、エージェントにMCPなどのツールを与えて自由にデータを読ませる方法と、アプリが入力を組み立てて渡し、決まった形式の出力を受け取る方法があります。前者は柔軟ですが、実行ごとに読むデータや手順が変わり、結果の再現性、テスト、安全性の確保が難しくなります。

## 決定

FB生成では、アプリが入力（計画、イベント、振り返り、集計値、直近の調子）を組み立ててエージェントに渡し、JSONで出力を受け取ります。エージェントはツールの使用とファイルの書き込みを許可しない設定で、空の一時ディレクトリを作業場所として起動します。出力はzodで検証し、形式が違えば1回だけ再試行します。数値はコードで計算した値を渡し、AIには計算させません。

対話的に記録を参照しながら相談したい場合に限り、ターミナルのClaude Code / CodexからMCPサーバー経由でデータを読めるようにします。

## 結果

Claude CodeとCodexを同じインターフェースで切り替えられ、偽のアダプタでテストできます。FBの品質はプロンプトと入力の組み立てで決まるため、プロンプトにバージョンを付け、入出力をログに残して改善します。
