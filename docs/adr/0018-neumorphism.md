# ADR-0018：画面の質感を、すりガラスからニューモフィズムに変える

- ステータス：採用（地の色と影の色は ADR-0019 で変更）
- 日付：2026-10-09

## 背景

画面は「すりガラスの静けさ」（DESIGN.md 1章）を原則に、色のにじみを置いた背景の上に、半透明のガラスの面（`--glass-1`〜`--glass-4`、`backdrop-filter`）を重ねて作ってきました。利用者から、見た目をニューモフィズム（面を地と同じ色で塗り、明るい影と暗い影で浮き出させたり、へこませたりする表現）に変えたいという要望が出ました。

ガラスの表現には、次の困りごともありました。

- 面の後ろがにじみで場所ごとに変わるため、axe が背景色を決められず、コントラストは「透明度を下げる」をエミュレートした画面でしか自動検査できない（DESIGN.md 7章）
- `backdrop-filter` は描画が重く、行ごとには使えない、動かせないといった制約を、画面ごとに気にする必要がある（2.3、2.7）

ニューモフィズムには、面の境目が影だけになり、要素が見分けにくく、押せる場所が分かりにくいという、よく知られた弱点があります。本文のコントラスト（NFR-06）と、押せることの分かりやすさ（NFR-29）を落とさないことを条件にします。

## 決定

利用者と次の4点を決めました。

| 論点 | 決定 | 見送った案 |
|---|---|---|
| 地の色 | 暖かい生成り（`#EEE9E1`）。影は左上に白、右下に暖かい茶 | 冷たいグレー（`#E4E9F0`）。今の暖かい印象とマメの色から離れる |
| 範囲 | 面（ペイン、カード、入力欄）と操作部品（副ボタン、セグメント、`kbd`、ステータスアイコン）を凸凹で表す。主ボタンと確定ボタンは塗りを残し、選択状態も藍色で示す | 主ボタンも含めて全部を地の色にする。主な操作が埋もれ、コントラストの検査が厳しくなる |
| 背景のにじみ | なくす。単色の地にする | ごく薄く残す。影の見え方が場所で変わる |
| マメ | 今のガラス玉の質感のまま | 粘土調に描き直す。キャラクターは画面の質感と切り離す |

**トークン。** `--glass-*` と `--blob-*` をやめ、次を足します。値の正本は実装の PR で DESIGN.md 2.3 に書きます。

| トークン | 案 | 使う場所 |
|---|---|---|
| `--surface` | `#EEE9E1`（`--ground` と同じ。振り返りの画面では `--ground-evening`） | すべての面 |
| `--neu-light` / `--neu-dark` | `rgba(255, 255, 255, 0.85)` / `rgba(163, 150, 130, 0.45)` | 影の2色 |
| `--neu-raised-1` | 4px の影（左上に明、右下に暗、ぼかし 10px） | ボタン、`kbd`、セグメントの外枠 |
| `--neu-raised-2` | 8px の影（ぼかし 20px） | ペイン、カード |
| `--neu-raised-3` | 14px の影（ぼかし 32px） | ダイアログ、コマンドパレット、バナー |
| `--neu-inset-1` | 内側に 3px の影（ぼかし 6px） | 入力欄、選んだ行、選んだセグメント、押下 |
| `--neu-inset-2` | 内側に 6px の影（ぼかし 12px） | エディタ、カレンダーの表などの大きなくぼみ |
| `--neu-edge` | `1px solid rgba(255, 255, 255, 0.5)` | 面の縁（影だけでは境目が弱いため） |

**押下は影を動かさない。** 2.7 の原則（動かすのは `transform` と `opacity` だけ）を守るため、押下は、要素の後ろに重ねた `--neu-inset-1` の層の `opacity` と、`--press-scale` で表します。ホバーの層（2.8）と同じ作り方です。

**見分けやすさを影だけに頼らない。** 面には `--neu-edge` の縁を付け、選んだ行は内側の影に加えて藍色の枠（`--row-selected-border`）を残します。OS の「コントラストを上げる」設定（`prefers-contrast: more`）では、縁を濃い線（`rgba(28, 27, 25, 0.24)`）にし、影を弱めます。フォーカスの藍色のリングは今のまま常に出します。

**透明度の設定。** 半透明の面がなくなるので、「透明度を下げる」設定で切り替える対象はなくなります。NFR-22 の該当部分は、実装の PR で requirements.md を直します。

## 結果

- `backdrop-filter` を使わなくなり、2.3 と 2.9 にある「ガラスの面は動かさない」「切り替え中はぼかしが後ろを見られない」といった制約がなくなる
- 面が不透明になるので、axe がふだんの画面でコントラストを判定できる。「透明度を下げる」をエミュレートした検査は、通常の画面の検査に置き換える
- Figma「mymind view design」の変数、エフェクトスタイル、部品、8枚のフレームを作り直す。`GlassPanel` は凸凹の面の見本に置き換える
- デスクトップアプリのアイコンの角丸の面（`--glass-opaque`）は `--surface` にする
- マメの体の質感（白の縁取り、ハイライト）は変えない。地が不透明になるので、見え方は今の「透明度を下げる」の画面に近くなる
- 進め方はロードマップの M8 に書く
