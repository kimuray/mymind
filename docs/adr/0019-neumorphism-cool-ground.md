# ADR-0019：ニューモフィズムの地の色を、冷たいグレーにする

- ステータス：採用
- 日付：2026-10-09

## 背景

ADR-0018 では、ニューモフィズムの地の色を暖かい生成り（`#EEE9E1`）にし、冷たいグレー（`#E4E9F0`）を見送りました。今の暖かい印象とマメの色に近いことを理由にしていました。

Figma の8枚のフレームを生成りで作り直して見たところ、利用者から「実際に見ると、冷たい色のほうがよい」という判断が出ました。

## 決定

**地の色を冷たいグレーにする。** ADR-0018 の決定のうち、地の色と影の色だけを次のように変えます。ほかの決定（凸凹にする範囲、背景のにじみをなくすこと、マメの質感、押下の作り方、見分けやすさの対策）は ADR-0018 のままです。

| トークン | ADR-0018 | この ADR |
|---|---|---|
| `--ground`（＝`--surface`） | `#EEE9E1` | `#E4E9F0` |
| `--neu-light` | `rgba(255, 255, 255, 0.85)` | `rgba(255, 255, 255, 0.9)` |
| `--neu-dark` | `rgba(163, 150, 130, 0.45)` | `rgba(163, 177, 198, 0.55)` |

影の大きさとぼかし（`--neu-raised-*`、`--neu-inset-*`）は変えません。値の正本は、実装の PR（#237）で DESIGN.md 2.3 に書きます。

**文字と状態の色は変えない。** `--ink-*` と状態色は暖かい色みのままにします。冷たい地の上で計算してもコントラストは足りる（`--ink-4` で約 6:1）ため、M8 では変えず、気になれば別に決めます。振り返りの画面の地（`--ground-evening`、`#E9E6EE`）も、冷たい地とつながる色なので変えません。

## 結果

- Figma の変数 `ground`、`neu-light`、`neu-dark` と、Components ページの地を、この値に変えた
- #237 で `tokens.css` と DESIGN.md に入れる値は、この ADR の値になる
- デスクトップアプリのアイコンの面（ADR-0018 で `--surface` にする）も冷たいグレーになる
