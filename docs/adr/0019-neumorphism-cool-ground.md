# ADR-0019：ニューモフィズムの地を冷たいグレーにし、ボタンと文字の色をそれに合わせる

- ステータス：採用
- 日付：2026-10-09

## 背景

ADR-0018 では、ニューモフィズムの地の色を暖かい生成り（`#EEE9E1`）にし、冷たいグレー（`#E4E9F0`）を見送りました。今の暖かい印象とマメの色に近いことを理由にしていました。

Figma の8枚のフレームを生成りで作り直して見たところ、利用者から「実際に見ると、冷たい色のほうがよい」という判断が出ました。続けて、主ボタンなどの色合いと、地に合わせたほかの色合いも見直したいという要望が出ました。

## 決定

**地の色を冷たいグレーにする。** ADR-0018 の決定のうち、地の色と影の色だけを次のように変えます。ほかの決定（凸凹にする範囲、背景のにじみをなくすこと、マメの質感、押下の作り方、見分けやすさの対策）は ADR-0018 のままです。

| トークン | ADR-0018 | この ADR |
|---|---|---|
| `--ground`（＝`--surface`） | `#EEE9E1` | `#E4E9F0` |
| `--neu-light` | `rgba(255, 255, 255, 0.85)` | `rgba(255, 255, 255, 0.9)` |
| `--neu-dark` | `rgba(163, 150, 130, 0.45)` | `rgba(163, 177, 198, 0.55)` |

影の大きさとぼかし（`--neu-raised-*`、`--neu-inset-*`）は変えません。値の正本は、実装の PR（#237）で DESIGN.md 2.3 に書きます。

**振り返りの画面も同じ地にする。** これまで振り返りの画面だけ地を `--ground-evening`（`#E9E6EE`）にしていましたが、やめて全画面を `--ground` にします。`--ground-evening` は最初の DESIGN.md からあったもので、要件や ADR に理由はありませんでした。ガラスのときは背景の大半がにじみで覆われ、違いは目立ちませんでした。ニューモフィズムでは面も地と同じ色で塗るため、画面全体の色が切り替わります。影は冷たいグレーに合わせた色なので藤色の地にはなじまず、振り返りに移るたびに画面の色が変わります。「夜に書く画面」らしさは、見出しや FB の文面で出せます。

**ボタンは、少し明るい藍と冷たい墨色にし、もっと出っぱらせる。** Figma に4案（今のまま／明るい藍＋冷たい墨／藍1色／弱いグラデーション）と、出っぱり方の3案（影を大きく／＋縁の面取り／＋膨らみ）を並べ、利用者が「明るい藍＋冷たい墨」に「影を大きく＋縁の面取り」を選びました。

| トークン | 今 | この ADR |
|---|---|---|
| `--button-primary-bg`（新規） | `--accent`（`#2F4B7C`） | `#3A5A94`（白い文字で 6.84:1） |
| `--button-confirm-bg` | `rgba(28, 27, 25, 0.88)` | `#26303F`（白い文字で 13.32:1） |
| `--button-raised-on-dark`（新規） | `--accent-shadow` | `--neu-raised-2` の影に、内側の面取り `inset 2px 2px 3px rgba(255, 255, 255, 0.28)`、`inset -2px -2px 4px rgba(0, 0, 0, 0.28)` |
| `--button-raised`（新規） | `--neu-raised-1` | `--neu-raised-2` の影に、内側の面取り `inset 2px 2px 3px rgba(255, 255, 255, 0.9)`、`inset -2px -2px 4px rgba(163, 177, 198, 0.35)` |

`--accent`（選択の印、着手中の状態色、フォーカスの輪）は変えません。主ボタンだけを `--button-primary-bg` に分け、選択や状態の藍とボタンの藍を別に調整できるようにします。ADR-0018 で「ボタンは `--neu-raised-1`」としていたものは、この `--button-raised*` に置き換えます（`kbd` とセグメントの外枠は `--neu-raised-1` のまま）。

**文字と灰色を、冷たい地に合わせる。** 暖かい茶色みの文字と灰色が、冷たい地とボタンの上で浮いて見えるため、明るさを保ったまま青みに寄せます。

| トークン | 今 | この ADR | 地の上のコントラスト |
|---|---|---|---|
| `--ink-1` | `#1C1B19` | `#1A1F29` | 13.53:1 |
| `--ink-2` | `#3F3B34` | `#3A4250` | 8.30:1 |
| `--ink-3` | `#4F4A42` | `#4A5363` | 6.35:1 |
| `--ink-4` | `#5A554C` | `#566070` | 5.21:1 |
| `--status-todo` / `--status-cancelled` | `#8A857B` | `#7F8898` | — |
| `--status-todo-bg` / `--status-cancelled-bg` | `rgba(120, 112, 98, 0.14)` | `rgba(110, 122, 142, 0.14)` | — |
| `--status-todo-text` / `--status-cancelled-text` | `#4A463F` | `#434B59` | バッジの上で 6.19:1 |

`rgba(28, 27, 25, …)` で作っている淡い層（`--hover-fill`、`--overlay`、`--kbd-border`、`--code-bg`、不透明な面の枠など）は、同じ不透明度のまま `--ink-1` の色（`rgba(26, 31, 41, …)`）にします。

**意味のある色は変えない。** `--accent`、中断・待ち・完了の状態色、タグの6色、マメの色は、色みそのものが意味（状態、タグ、調子）を持つので変えません。

## 結果

- Figma の変数 `ground`、`neu-light`、`neu-dark` と、Components ページの地を、この値に変えた。`PC/振り返り` も `ground` にし、変数 `ground-evening` は消した
- #237 で `--ground-evening` のトークン、`base.css` の振り返りの画面の地の切り替え、`contrast.test.ts` の振り返りの地の分を消し、DESIGN.md 2.1・4.7・4.19 を直す
- #237 で `tokens.css` と DESIGN.md に入れる値は、この ADR の値になる。`contrast.test.ts` もこの値で計算する
- Figma に変数 `button-primary`・`button-confirm` と、エフェクトスタイル `ニューモ / ボタン（濃い塗り）`・`ニューモ / ボタン（地の塗り）` を足し、文字と灰色の色を塗り替えた。`ink-4` より薄い文字（`#6F695E`、`#9A958A`）が残っていたので `ink-4` にそろえた
- デスクトップアプリのアイコンの面（ADR-0018 で `--surface` にする）も冷たいグレーになる
