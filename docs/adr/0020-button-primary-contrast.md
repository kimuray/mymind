# ADR-0020：主ボタンの塗りを、処理中の点滅でも読めるよう少し濃くする

- ステータス：提案
- 日付：2026-10-09

## 背景

ADR-0019 で、主ボタンの塗り（`--button-primary-bg`）を `#3A5A94` に決めました。止まっているときの白い文字のコントラストは 6.84:1 で、NFR-06（4.5:1 以上）を満たします。

ところが、処理中のボタンは控えめに点滅し、いちばん薄いところで要素ごと不透明度 0.8 になります（DESIGN.md 4.19）。このとき下の地（`#E4E9F0`）が透けるので、白い文字と塗りの差が縮まります。#237 で `contrast.test.ts` を新しい値で計算したところ、`#3A5A94` では 4.37:1 になり、4.5:1 に届きませんでした。

## 決定

**主ボタンの塗りを `#36558C` にする。** 色みは ADR-0019 で選んだ「明るい藍」のまま、明るさだけを少し下げます。

| 値 | 止まっているとき | 点滅のいちばん薄いところ |
|---|---|---|
| `#3A5A94`（ADR-0019） | 6.84:1 | 4.37:1 |
| `#37578F` | 7.19:1 | 4.53:1 |
| `#36558C`（この ADR） | 7.41:1 | 4.63:1 |

4.5:1 をわずかに超えるだけの `#37578F` ではなく、地の色の小さな調整にも耐えるよう、少し余裕のある `#36558C` にします。

見送った案は次のとおりです。

- **点滅を弱める（不透明度 0.8 → 0.85 など）**：読み込み中の文など、ほかの点滅にも効くため、主ボタンのためだけに全体の見え方を変えることになる
- **主ボタンだけ、点滅で塗りを薄くしない**：処理中の表し方が、ボタンの種類ごとに分かれる

## 結果

- `tokens.css` と DESIGN.md 4.4 の `--button-primary-bg` は `#36558C` にする。Figma の変数 `button-primary` も同じ値にした
- `contrast.test.ts` は、点滅のいちばん薄いところの主ボタンの文字を、この値で確かめる
- ADR-0019 の、ほかの決定（確定ボタン、ボタンの影、文字の色）は変えない
