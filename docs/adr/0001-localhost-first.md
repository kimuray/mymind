# ADR-0001：localhost を主軸にする

- ステータス：採用
- 日付：2026-09-22

## 背景

当初は、スマホから使えるようにCloudflare Workers と D1 でホスティングし、ローカルのAIエージェントは夜間バッチでAPI経由で書き戻す構成を検討していました。しかし、このツールの中心的な価値は、手元のClaude Code / Codexを使ったフィードバックにあります。クラウドに置くと、アプリからエージェントを直接起動できず、連携のためにサービストークン、定期実行、書き戻し用のAPIが必要になります。

## 決定

アプリはPC上のNode.jsサーバーとして `127.0.0.1` で動かし、ブラウザから使います。サーバーがエージェントを子プロセスとして直接起動します。スマホ対応とインターネット経由の利用は、現時点では対象外にします。

## 結果

エージェント連携が単純になり、振り返りを保存した直後にFBを生成できます。一方で、PCが起動していないと使えません。また、ローカルサーバーが外部のWebページから操作されないよう、Host・Originの検証とセッショントークンが必須になります。将来のクラウド版に備えて、DBアクセスとエージェント起動はインターフェースの裏に隠し、HonoとDrizzleを使ってWorkers / D1 へ移しやすい形にしておきます。
